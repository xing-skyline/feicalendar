# 飞历 FeiCalendar

飞历是一款面向 Windows 的开源桌面日历，用于安排工作、学习和个人生活。支持日、三日、周、月、年与日程列表六种视图，可自定义教学周，并让本地日历、CalDAV、WebDAV 网盘、ICS 订阅和飞书日历在同一个窗口中同时使用。

日程先保存在本机。需要多端同步时，可以按自己的设备和服务选择连接方式，也可以同时启用多个来源。

[下载 Windows 便携版](https://github.com/xing-skyline/feicalendar/releases/latest) · [查看版本记录](https://github.com/xing-skyline/feicalendar/releases) · [反馈问题](https://github.com/xing-skyline/feicalendar/issues)

## 快速开始

1. 在 Releases 下载 `FeiCalendar-0.5.1-win-x64.exe`，放到准备长期使用的文件夹。
2. 双击启动。首次运行需要等待程序解包，运行环境已随便携版提供。
3. 点击“新建日程”或直接点击日历中的时间格，即可使用本地日历。
4. 如需同步，打开“设置 → 日历连接”，添加所用服务，再到“通用设置”选择默认日历。
5. 如需显示教学周，在“设置 → 教学周”填写第一教学周内任意一天和学期总周数。

当前发布 Windows x64 便携版。发布文件采用普通可执行文件分发，尚未配置代码签名证书。可通过同一 Release 中的 `SHA256SUMS.txt` 核对下载文件。

```powershell
Get-FileHash .\FeiCalendar-0.5.1-win-x64.exe -Algorithm SHA256
```

便携版可以移动、改名后启动。数据按当前 Windows 用户保存在 `%APPDATA%\FeiCalendar`。移动 EXE 后再次运行，会更新开始菜单中的飞历入口和任务栏重启路径。换一台电脑时，需在新设备上配置连接。

从 0.5.1 起，可在“设置 → 软件更新”或托盘右键菜单中检查新版、下载并执行升级。0.4.x 用户先退出旧版，再下载运行 0.5.1，以启用后续应用内升级。项目源码目录中的 `启动飞历.cmd` 也可用于启动对应版本。

## 日历与日程

| 功能       | 用法                                                       |
| ---------- | ---------------------------------------------------------- |
| 六种视图   | 顶部切换日、三日、周、月、年和日程列表，启动时恢复上次视图 |
| 时间安排   | 点击或拖选时间新建日程，拖动改期，拖动边缘调整时长         |
| 月历导航   | 左侧迷你月历跳转日期，月视图点击日期进入当天               |
| 日程内容   | 标题、起止时间、全天、跨天、地点、描述和提前提醒           |
| 重复日程   | 每天、工作日、每周、每月和每年重复，支持单次例外           |
| 多日历     | 自定义名称、颜色和显示状态，为新日程选择所属日历           |
| 查找与导出 | 搜索已缓存日程，导出 ICS 文件                              |
| 外观       | 浅色与深色主题，可收起右侧日程栏                           |

本地与 WebDAV 日历支持修改单次重复日程或整个系列。CalDAV 支持新建重复系列、编辑和删除单次日程。已有 CalDAV 与飞书远程系列的整体管理可在来源服务中完成。

### 托盘和提醒

“设置 → 通用设置”中的“关闭窗口后最小化到托盘”默认开启。点击窗口叉号后，窗口隐藏，后台继续执行自动同步和桌面提醒。

- 点击托盘图标或右键选择“打开飞历”，恢复窗口。
- 右键选择“退出飞历”，完成已进入执行队列的操作后结束程序。
- 关闭“最小化到托盘”选项后，窗口叉号会退出应用。
- 桌面提醒在飞历运行期间生效，并受 Windows 通知和专注设置影响。

### 显示与默认值

设置中可调整每周起始日、周末显示、12 / 24 小时制、时间轴起止小时、新日程默认时长、默认提醒，以及自动同步开关和间隔。拖选时间范围创建日程时，使用实际选中的起止时间。

当前版本按北京时间 `Asia/Shanghai` 显示和编辑日程。搜索覆盖已缓存到本机的数据，云端日程随浏览的日期范围读取。

## 桌面常驻日历

在“设置 → 桌面日历”打开面板，也可以右键单击系统托盘中的飞历图标，勾选“开启桌面日历”。开启状态会保存，下一次启动飞历时恢复。

面板提供“月历与当日日程”和“未来两周日程清单”。月历上的圆点表示当天有日程，点击日期查看当日安排。点击日程打开主窗口编辑，点击加号新建日程。面板沿用主窗口中各日历的显示状态、日程颜色和教学周设置，保存修改后两边一起刷新。

外观设置可选浅色、深色或跟随系统，提供六种预设颜色和自定义颜色。背景不透明度可在 0%–100% 之间调整，数值越小越透明，0% 为透明背景。拖动标题栏可以移动，拖动右下角可以调整大小，位置和尺寸会保存在本机。开启“锁定位置和大小”可避免误拖。

托盘右键菜单包含以下操作。

| 操作 | 效果 |
| --- | --- |
| 开启桌面日历 | 启用或停用面板，与设置页开关同步 |
| 暂时隐藏／显示桌面日历 | 切换本次运行期间的可见状态 |
| 桌面日历外观 | 打开外观设置 |
| 锁定桌面日历位置 | 固定当前的位置与大小 |
| 重置桌面日历位置 | 在主屏幕恢复默认位置和尺寸 |
| 关闭桌面日历 | 停用面板，下次启动仍保持关闭 |
| 退出飞历 | 退出主窗口、桌面面板和后台进程 |

Windows 环境下，面板作为 Explorer 桌面宿主中的子窗口显示，可与桌面图标一起常驻。桌面宿主暂时不可用时使用独立面板，设置页会显示当前状态，并定期尝试恢复嵌入。不同 Windows 桌面管理工具和系统版本的行为可能有差异。

## 检查和安装更新

“设置 → 软件更新”提供手动检查。自动检查默认开启，在启动后和持续运行每满一天时访问本项目的 GitHub Releases，用户可在设置中关闭。

1. 检查到新版后，查看版本说明并点击“下载”。
2. 下载完成后验证 SHA-256，校验通过才显示“退出并升级”。
3. 点击“退出并升级”，程序等待正在执行的保存与同步结束，然后退出。
4. 升级助手等待便携启动器释放文件，替换当前 EXE，并重新启动飞历。

替换时沿用当前 EXE 的文件名和位置，包括自行改名的便携版。旧程序保存在旁边的 `.exe.previous` 文件中。替换或启动失败时尝试恢复原程序，下次启动可在软件更新页看到错误。下载失败可重新检查并下载。下载缓存位于 `%APPDATA%\FeiCalendar\updates`，日历数据保存在同一用户配置目录下的独立文件中。

应用内替换要求 Windows x64 便携版所在文件夹可写。若网络无法访问 GitHub，或设备限制升级助手运行，可从 Releases 手动下载，退出飞历后更新程序文件。开发模式和解包目录提供检查与发布页入口。

### 向用户发布新版

仓库的 GitHub Actions 工作流会在推送版本标签时检查版本号、安装锁定依赖、运行类型检查和测试、构建 Windows x64 便携版、校验图标，并创建含 EXE 和 `SHA256SUMS.txt` 的正式 Release。

例如准备发布 0.5.2，在完成修改并提交后执行以下命令。

```powershell
npm version 0.5.2
git push origin main --follow-tags
```

`npm version` 更新 `package.json` 与锁文件并创建对应标签。标签必须与包版本一致，例如 `v0.5.2`。发布成功后，客户端下一次检查就能发现新版。只推送源代码时，客户端会继续使用最近一次正式 Release。也可手动创建正式 Release，上传按 `FeiCalendar-版本号-win-x64.exe` 命名的程序与对应 SHA-256 校验文件。客户端跳过草稿、预发布版本和低于当前安装版本的发行。

工作流使用 GitHub 提供的仓库令牌发布构建产物。构建内容来自已提交的源代码和依赖，日历服务凭据由每位使用者在本机配置。

## 自定义教学周

在“设置 → 教学周”选择第一教学周内任意一天，填写教学周总数，然后点击“保存教学周设置”。每周起始日沿用日历显示设置，可选择星期一、星期日或星期六。

例如，每周从星期一开始，选择 2027 年 3 月 3 日，则 3 月 1 日至 3 月 7 日属于教学第 1 周。总周数设置为 18 时，标记连续显示到第 18 周。跨月、跨年的学期会连续编号。

顶部显示选中日期所属的教学周，月视图和年视图在周行位置显示周数。学期起点之前和总周数之后的日期留空。

首次使用时起始日期留空，总周数预填 20，可自定义为 1–104 周。每学期可以重新设置。清空起始日期并保存即可关闭教学周显示。WebDAV 连接可选同步教学周配置。

### 多个连接同时生效

在“日历连接”中重复添加即可。连接可分别启用或暂停，日历可分别显示或隐藏。比如同时启用个人 iCloud 日历、工作飞书日历、NAS 上的家庭日历和一份公共 ICS 订阅。

每条日程属于一个日历，写回目标由所属日历决定。多个来源会一起展示，各自保留独立数据。跨服务自动复制和镜像暂未实现。新建日程时可选择目标日历，也可以设置默认目标。

已有本地日历可通过左侧日历右侧的“…”菜单迁移到一个可写云端日历。确认目标后，该日历中的日程会进入目标服务的同步队列。

连接暂停时，本地修改进入待同步队列，恢复后继续处理。隐藏日历仅影响界面显示。

### 电脑和手机

电脑与手机可通过双方都支持的日历服务交换日程。iPhone 可使用系统日历的 CalDAV 账号，Android 可通过 DAVx⁵ 等兼容客户端接入。使用飞书账号时，手机侧可在飞书日历中查看和修改。各服务和客户端的授权要求以其文档为准。[Nextcloud iOS 配置](https://docs.nextcloud.com/server/stable/user_manual/en/groupware/sync_ios.html) · [Nextcloud Android 配置](https://docs.nextcloud.com/server/stable/user_manual/en/groupware/sync_android.html)

飞历目前交付 Windows 客户端。WebDAV 网盘中的 `calendar-v1.json` 是飞历的数据格式，手机原生日历通常通过 CalDAV 读取日历内容。移动版飞历和通用手机 WebDAV 日历读取功能暂未提供。

## 配置 CalDAV

1. 打开“设置 → 日历连接 → 添加连接”。
2. 选择“通用 CalDAV”“iCloud 日历”或“Nextcloud 日历”预设。
3. 填写连接名称、HTTPS 服务地址、用户名和应用专用密码。
4. 根据用途设置“以只读方式连接”。写入同时需要服务端授予当前账号编辑权限。
5. 保存连接并同步，在左侧勾选要显示的日历。

| 服务           | 地址与凭据                                                           |
| -------------- | -------------------------------------------------------------------- |
| iCloud         | 预设地址 `https://caldav.icloud.com`，使用 Apple 账号和 App 专用密码 |
| Nextcloud      | 使用实例日历设置中提供的 CalDAV 地址和应用密码                       |
| NAS / 自建服务 | 使用服务端提供的 CalDAV 地址和相应账号                               |
| 其他 CalDAV    | 使用“通用 CalDAV”，填写服务提供者给出的 HTTPS 地址                   |

服务端修改密码、撤销授权或调整访问权限后，需要更新连接配置。iCloud 的 App 专用密码可在 Apple 账号设置中生成。[Apple App 专用密码说明](https://support.apple.com/en-gb/102654)

CalDAV 更新使用 ETag 条件写入检测并发修改，并保留原始 UID 和外部扩展字段。部分服务器会限制发现接口、日历写权限或重复日程能力，实际兼容性依赖服务端实现。

## 配置 WebDAV 网盘

提供坚果云、Nextcloud / NAS 和自定义 WebDAV 预设。服务地址必须支持 WebDAV 文件操作，账号建议使用该服务提供的应用密码。

1. 在“日历连接”添加 WebDAV 连接，填写 HTTPS 文件夹地址、用户名和密码。
2. 坚果云预设地址为 `https://dav.jianguoyun.com/dav/`。其他服务使用其提供的 WebDAV 地址。
3. 保存后，该连接会创建一个云端日历。
4. 另一台电脑中的飞历填写相同地址、账号和目录，即可共享该日历。
5. 需要同步学期安排时，勾选“同步教学周配置”。

程序使用所填目录下的 `FeiCalendar/calendar-v1.json`。同步文件包含该连接所属日程、完成状态、重复规则和删除标记。启用教学周同步后，还包含起始日期、总周数和每周起始日。

每个连接拥有独立的同步文件与本地状态。多个网盘连接可以同时使用，日程按所属连接写入对应目录。网盘的专有文件接口需要对应适配器，当前支持提供 WebDAV 协议的服务。

服务需支持 GET、PUT、MKCOL、强 ETag 和条件写入。现有同步文件最大支持 20 MB。不同日程的修改会合并，同一日程或教学周配置发生冲突时，在“同步记录”选择本地或云端版本。

WebDAV 通过 HTTPS 传输，远端 JSON 文件保存可读日程内容。当前版本尚未实现端到端加密，网盘账户权限和服务端存储策略会影响数据访问范围。

## 配置 ICS / Webcal 订阅

选择“ICS / Webcal 链接”，填写服务提供者给出的订阅 URL。支持重复规则、例外日期、单次调整、时区和全天日程。

ICS 连接按订阅内容更新，编辑在提供该订阅的来源服务中完成。订阅 URL 可能包含访问令牌，保存时按连接凭据加密。公开问题反馈时应删除完整订阅地址。

## 可选的飞书日历集成

飞书连接通过开放接口与官方开源 lark-cli 组件提供日历访问。使用者配置自己的应用和账号授权，飞书只是可选连接之一。

### 账号双向同步

1. 在飞书开放平台创建或准备一个可供当前用户使用的自建应用，按所在组织要求启用、发布并开放权限。
2. 在“日历连接”展开“配置飞书自建应用”，填写自己的 App ID 和 App Secret。
3. 点击“授权飞书账号”，打开授权页面或扫描二维码，完成后点击“我已授权，完成连接”。
4. 同步后，在“通用设置”选择一个可写飞书日历作为默认日历，或在每次新建时选择它。

连接使用 `user` 身份，并请求以下权限。

```text
calendar:calendar:read
calendar:calendar.event:read
calendar:calendar.event:create
calendar:calendar.event:update
calendar:calendar.event:delete
offline_access
```

App Secret 经标准输入交给 lark-cli，组件管理本机凭据与授权续期。配置应用会更新本机共享的 lark-cli 应用配置，使用同一配置的其他工具也会受到影响。[飞书开放平台](https://open.feishu.cn/) · [lark-cli 项目与许可证](https://github.com/larksuite/cli)

授权凭据可在有效期内自动刷新。长时间停用造成刷新凭据过期、用户撤销授权、应用被删除或停用等情况，需要重新授权。二维码过期后可重新发起授权获取新二维码。

已有飞书重复系列的单次日程可以编辑，整个系列可通过“在飞书中打开”进入来源服务管理。已有日程的提醒由飞书管理，新建日程可设置提前提醒。

### 飞书 CalDAV 订阅

在飞书桌面端的日历设置中获取 CalDAV 服务器地址、用户名和密码，然后在飞历选择“飞书 CalDAV 订阅”预设。常用服务器为 `https://caldav.feishu.cn`。

飞书 CalDAV 提供单向读取，需要写回时使用上面的账号集成。同一个日历同时接入多个来源时，可在左侧隐藏重复来源。[飞书第三方日历同步说明](https://www.feishu.cn/hc/zh-CN/articles/079695875192-第三方日历同步-管理员手册)

## 数据、隐私与恢复

### 本地保存

| 位置                                  | 内容                                           |
| ------------------------------------- | ---------------------------------------------- |
| `%APPDATA%\FeiCalendar\calendar.json` | 日历、缓存日程、待同步队列和设置，以 JSON 保存 |
| 同目录的 `calendar.json.backup`       | 上一个保存快照，供恢复使用                     |
| 同目录的 `connections.encrypted`      | CalDAV / WebDAV 账号、密码和订阅地址的加密存储 |
| 同目录的 `app-icon-*.ico`             | Windows 任务栏、托盘和开始菜单使用的图标       |
| 同目录的 `desktop-panel.json`        | 桌面面板的位置和尺寸                           |
| 同目录的 `updates` 文件夹            | 下载的新版本、升级状态与本地替换信息           |
| 本机 lark-cli 配置与凭据存储          | 飞书应用信息和用户授权，由连接组件管理         |

连接凭据使用 Electron `safeStorage`，通过 Windows 当前用户的保护机制加密。日程数据库和备份以可读 JSON 保存。跨 Windows 用户或设备迁移时，需要重新填写连接凭据和完成账号授权。

备份本地日程前，先通过托盘退出飞历，再复制数据目录到自己的备份位置。数据库损坏时，可在程序完全退出后保留损坏文件，将上一份 `calendar.json.backup` 复制为 `calendar.json` 后重启。恢复快照会回到那次保存时的日程和队列状态。

### 网络传输

联网操作直接访问用户配置的日历、订阅、网盘服务和飞书授权接口。WebDAV 同步采用明确的日程字段清单，仅同步该连接的数据与用户勾选的教学周配置。每台设备单独配置连接凭据。

更新功能通过 HTTPS 访问 GitHub Releases API 和 GitHub 发行文件下载域名，请求包含应用版本与标准网络连接信息。日程、日历服务账号和连接凭据用于各自的同步服务。自动检查可在软件更新页关闭。

提交问题时请使用虚构日程复现，并删去真实姓名、会议内容、订阅链接、账号、密码、App Secret、令牌和授权二维码。项目的 `.gitignore` 排除了运行数据、凭据、授权目录、测试截图、日志和构建输出。

### 离线与冲突

本地修改立即保存。云端写入进入持久化队列，失败后保留待处理状态。飞书创建请求使用持久化幂等键，CalDAV 与 WebDAV 使用条件写入来识别并发变化。

出现冲突后，打开“同步记录”检查相关日程，选择“采用云端版本”或“保留本地并同步”。选择会决定后续保存的内容。WebDAV 同步完成标记，其他来源的完成标记保存在本机。

## 常见问题

### 可以同时用飞书、iCloud 和网盘吗？

可以。每个连接独立启用、暂停和显示，日程写回其所属日历对应的服务。

### 为什么新日程只在电脑上出现？

检查日程所属日历。选择“本地”会保存在本机。若要在其他设备查看，可选择一个可写云端日历，并确认连接已启用、账号有效、同步队列成功完成。

### 点击叉号后为什么还在运行？

“关闭窗口后最小化到托盘”默认开启。彻底退出使用托盘右键菜单中的“退出飞历”，也可在设置中关闭该选项。

### 能否同步所有常用网盘？

当前网盘同步基于 WebDAV。提供兼容接口的服务可以配置，其他服务的专有 API 需要单独开发接入。

### 为什么不能编辑某个日历？

ICS 和飞书 CalDAV 属于只读来源。其他 CalDAV 连接同时受本地只读选项和服务端访问权限控制。确认账号获得编辑权限后重新同步。

### 真实服务的兼容性验证到什么程度？

飞书账号集成经过真实账号的创建、修改、回读和删除验证。通用 CalDAV / WebDAV 的双向同步、并发冲突与多连接行为通过模拟服务测试。iCloud、Nextcloud、坚果云和各类 NAS 的真实账户兼容性仍需持续验证，预设提供对应的配置入口。

## 本地开发

建议使用 Windows x64、Node.js 22 和 npm。安装依赖时会下载 Electron 和 lark-cli 的对应平台组件。

```powershell
git clone https://github.com/xing-skyline/feicalendar.git
cd feicalendar
npm ci
npm run dev
```

| 命令                    | 用途                                                   |
| ----------------------- | ------------------------------------------------------ |
| `npm run check`         | TypeScript 类型检查                                    |
| `npm test`              | 日程格式、重复例外、时区、队列恢复和同步冲突测试       |
| `npm run build`         | 汇集第三方许可，构建界面与 Electron 主进程             |
| `npm run test:desktop`  | 独立数据目录中的桌面交互、六种视图、教学周和多连接验证 |
| `npm run dist`          | 构建 Windows x64 便携版，并检查内外层 EXE 图标资源     |
| `npm run test:icons`    | 比较便携启动器与应用 EXE 的全部图标尺寸                |
| `npm run test:portable` | 独立中文路径、系统 PATH、移动改名与重启验证            |
| `npm run test:widget`   | 桌面嵌入、托盘开关、外观、日程联动与重启恢复验证       |
| `npm run licenses`      | 按锁文件重新生成第三方许可汇总                         |

桌面与便携测试会打开真实窗口，请在方便时运行。测试数据目录独立于日常日程数据。`FEICALENDAR_DATA_DIR` 可覆盖飞历数据目录，但 lark-cli 仍使用其自身的本机配置，涉及真实账号的授权或写入操作应单独管理。

### 项目结构

```text
electron/          主进程、数据存储、凭据保护、同步服务和协议适配
src/               React 界面、日历视图、设置与共享数据模型
scripts/           开发、构建、许可汇总与桌面验证脚本
tests/             同步、数据格式与日历逻辑测试
build/             应用图标
release/           本地构建输出，由 Git 忽略
```

技术栈包括 Electron、React、TypeScript、FullCalendar、tsdav、node-ical、ICAL.js 和 lark-cli。依赖版本由 `package-lock.json` 固定。
